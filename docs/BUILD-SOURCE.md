نظام معرض حور — الشيفرة المصدرية للإصدار 6.0.3
===================================================

هذه حزمة الشيفرة المصدرية الكاملة لبناء البرنامج من أوله.

محتويات الحزمة
--------------
server.ts              الخادم (Express + SQL.js) — كل منطق الأعمال والتقارير
electron-main.cjs      نافذة Electron الرئيسية وقائمة "حول البرنامج"
preload.cjs            جسر آمن بين الواجهة والنظام
src/App.tsx            هيكل التطبيق وتبديل التبويبات
src/components/        19 شاشة للواجهة (نقطة البيع، الفواتير، العملاء، ...)
src/services/api.ts    طبقة الاتصال بالخادم
src/types.ts           أنواع البياناتShared بين الواجهة والخادم
src/__tests__/         اختبارات وحدة (9 اختبارات)
build/                 أدوات البناء: الأيقونات + سكربتات + نسخة 7za
package.json           إعدادات المشروع ون scripts البناء
vite.config.ts         إعدادات بناء الواجهة
tsconfig.json          إعدادات TypeScript

متطلبات البناء
--------------
- Node.js 18 أو أحدث (اختُبر على 24.20 LTS)
- Windows 10 / 11 (64 بت)

خطوات البناء
-------------
1. فك الضغط في مجلد فارغ.

2. ثبّت الحزم:
       npm install

3. شغّل اختبارات الوحدة والتأكد من سلامة الشيفرة:
       npm run test
       npm run lint

4. ابنِ نسخة الواجهة والخادم فقط (بدون مثبّت):
       npm run build

5. ابنِ مثبّت Windows كاملاً:
       npm run electron:build

6. الناتج:
       - الحزمة غير المضغوطة:  dist-installer-v603\
       - ملف التثبيت:         dist-installer-v603\HawrGallery-Setup.exe

ملاحظة مهمة عن الخطوة 5
------------------------
خطوة البناء تحتاج برنامج 7-Zip لأن electron-builder يفشل مع الروابط الرمزية
(symbolic links) على بعض أنظمة Windows. المشروع يتضمّن حلاً جاهزاً في:
       build\7za-wrapper-build.ps1
ويُستدعى تلقائياً عبر الأمر  npm run fix:7za  قبل البناء.

ملاحظة عن الملفات الثنائية
---------------------------
ملفات الأيقونات (icon.ico / icon.png) محفوظة داخل مجلد build بصيغتها
الثنائية. لو تعطلت، استرجعها من النسخ النصية:
       node build\restore-binaries.mjs

متغيرات البيئة
---------------
انسخ .env.example إلى .env وعدّل القيم عند الحاجة.
المتغيرات المهمة:
       HAWR_DATA_DIR   مجلد تخزين قاعدة البيانات (افتراضياً %%APPDATA%%\hawr-gallery)
       HAWR_NO_LISTEN   اضبطه على 1 لتشغيل الخادم بلا listening على المنفذ

أوامر مفيدة أثناء التطوير
--------------------------
       npm run dev          تشغيل الخادم فقط على المنفذ 3000
       npm run electron:dev تشغيل التطبيق كاملاً مع الواجهة
       npm run preview      معاينة نسخة البناء

بنية قاعدة البيانات
-------------------
تُستخدم sql.js (SQLite يعمل داخل الذاكرة) ولا يحتاج خادم قواعد بيانات منفصل.
تُحفظ قاعدة البيانات في ملف واحد يسهل نسخه احتياطياً.
