# إرشادات بناء مثبت Windows EXE لنظام معرض حور (Hawr Gallery Setup)

تم تصميم النظام ليعمل كتطبيق Windows مستقل بالكامل دون الحاجة إلى اتصال بالإنترنت، مع محرك قاعدة بيانات SQLite داخلي محمي من مشاكل القفل (`EPERM Permission Denied`).

---

## 1. خطوات تجميع وبناء ملفات التشغيل
من مجلد المشروع، شغّل الأمر التالي لبناء واجهة React وتجميع خادم Node.js في ملف واحد (`dist/server.cjs`):

```bash
npm run build
```

---

## 2. خيارات التثبيت المضمنة في معالج الإعداد (Inno Setup)
ملف الإعداد `installer/hawr-installer.iss` يحتوي على:
1. **وضع التحديث (Update - Keep Data)**:
   - يحافظ على قاعدة البيانات السابقة `hawr-gallery.sqlite` في مجلد `data/`.
   - يأخذ نسخة أمان تلقائية في مجلد `backups_pre_install/` قبل التثبيت لضمان سلامة بيانات المعرض والمكتبة.
2. **وضع التثبيت النظيف (Clean Install - Fresh Start)**:
   - يتيح بدء النظام من الصفر لسنة مالية جديدة مع حفظ نسخة احتياطية من البيانات القديمة تلقائياً كإجراء احترازي.
3. **حماية ملفات النسخ الاحتياطية**:
   - لا يتم حذف أو استبدال ملفات النسخ الاحتياطية السابقة أثناء التثبيت أو التحديث.

---

## 3. بناء ملف التثبيت (.exe)
باستخدام برنامج [Inno Setup Compiler](https://jrsoftware.org/isdl.php):
1. افتح ملف `installer/hawr-installer.iss`.
2. اضغط على **Build / Compile** (Ctrl + F9).
3. سينتج ملف المثبت المستقل في مجلد `dist-installer/Setup-HawrGallery-v2.4.0.exe`.
